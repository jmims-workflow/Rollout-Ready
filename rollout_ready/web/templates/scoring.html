How scoring works

Rollout Ready runs your new version on a small set of saved test inputs, scores every output, and compares it with the version your team uses today.

1. Averages hide problems

The verdict looks at how many test cases got worse, not at the average score. A change can lift the average while quietly breaking the cases you care about.

In the example, version 3 of the follow-up email raised the average from 3.6 to 3.9, but two emails stopped answering the customer's questions. So the verdict is "Not ready to roll out."

  • Worse: the score dropped by 0.5 or more, or an automatic check that used to pass now fails.
  • Better: the score rose by 0.5 or more, or a check that used to fail now passes.
  • No clear change: anything smaller. One run always varies a little.

Then:

  • Nothing worse and at least one better: Ready to roll out.
  • Nothing worse and nothing better: No clear difference.
  • Some worse, but more cases better than worse: Not ready to roll out. Fix the worse cases first.
  • Some worse, and no more better than worse: Keep the current version.

2. Test cases are cheap

A test case is only an input: what someone on your team would paste in. Nobody has to write the ideal answer. Six to eight cases is plenty, as long as they include the hard ones.

A good habit: when a real output goes wrong, add that input as a test case, with names and details changed.

3. Two kinds of scoring

Automatic checks are plain rules run by code, like a word limit, words that must not appear, or words that must. They are free, instant and always give the same answer.

The judge is Claude, scoring each part of what good looks like from 1 to 5 with a one-sentence reason. A case's score is the average of those scores.

4. Blind, independent judging

The judge scores one output at a time. It is never told which version wrote it, and never sees the other version's output, so it can't take sides. Because each output is scored on its own, saved scores can be reused: only your new version needs to run.

The judge is a model and can be wrong, so read the reasons on any case that got worse before you decide.
